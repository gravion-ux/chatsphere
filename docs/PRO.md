# ChatSphere — Paid tier

## Why a paid tier exists here

ChatSphere is a deployable real-time chat application. Teams that want a
chat instance without operating MongoDB, sockets, and upgrades themselves
have a concrete hosting and support need. That operation is what the paid
tier serves.

## Free (this repository, MIT)

- Direct and group chat, presence, typing indicators, message history
- React client and Express/Socket.io server, self-hosted
- Full source under the MIT license

No free feature is gated in code. Paid packaging is documentation and
services only, so self-hosted deployments keep working exactly as before.

## Paid (hosted operation and support)

- Hosted ChatSphere instance (the web application already exists in this
  repository; paid hosting is a scoped deployment service)
- Managed upgrades, backups, and deployment review
- Priority support
